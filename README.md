
# Enterprise AI Assistant

An independently developed portfolio project exploring applied AI engineering, retrieval-augmented generation (RAG), backend development, and enterprise workflow automation.

## Project Status
🚧 In development — initial planning phase.

## Problem Statement
Organizations often store important information across multiple documents, making it difficult for employees to retrieve accurate answers efficiently.

## Proposed Solution
An AI-powered document assistant that retrieves relevant information, generates grounded answers, and provides citations to original sources.

## Planned Features
- Document upload and text extraction
- Semantic search using embeddings
- Retrieval-augmented question answering
- Source citations
- Backend APIs and database integration
- Automated tests and AI response evaluation
- Optional workflow automation

## Planned Tech Stack
- Backend: Python, FastAPI
- Frontend: Next.js
- Database: PostgreSQL and pgvector
- AI: LLM API and embedding model
- Deployment: To be determined
